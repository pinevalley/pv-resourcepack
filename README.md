# Pine Valley Resource Pack

- `pack/` is the resource pack (zipped as-is), `source/` holds Blockbench projects.
- Every push to `pack/` on `main` creates a release with `pinevalley.zip` and its SHA-1.
- Latest pack: https://github.com/pinevalley/pv-resourcepack/releases/latest/download/pinevalley.zip
- Latest hash: https://github.com/pinevalley/pv-resourcepack/releases/latest/download/pinevalley.zip.sha1
